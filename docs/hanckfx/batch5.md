## 6. The team structure behind a $1M+/month trading info business

Four departments: content, back end, sales, fulfillment. Team structure + reverse-engineered numbers per revenue phase. "A trading info business is supposed to be simple, lean, high margins, and easy to scale."

- OFFER
  - $0-30k/mo: sell **1-on-1 high-ticket mentorship**. Max out 1-on-1 at ~$30-50k/mo, then switch to **group coaching as main offer**.
  - Hanck's own B2B offer: no fulfillment team; "If I run out of capacity, all I should do is raise prices" — fewer clients, more per client, keep it 1-on-1.
- FUNNEL
  - Phase 1 back end: "a few VSLs, a few landing pages, a few funnels, a few appointment reminders and a few pre-qual assets."
  - If show rate <80%: improve appointment reminders, post-booking process, post-booking VSL, triage scripts, pre-call assets.
  - Funnel math benchmarks (conservative): YouTube views -> landing page visitor **5%** (his at $1.5M/mo: 6%); landing page visitor -> booked call **10%** (his: 10.8%); show rate **80%** (his: 90%+); close rate **50%** (his: >50%); AOV **$3.5k** (his: >$3.5k).
  - Instagram = brand/top-of-mind + story sequences + nurture -> funnel to YouTube; "YouTube is actually what's going to sell... Instagram views won't."
- CONTENT
  - $0-10k: no team; just ideation + creation frameworks (when/how/where/what to post). Crack content yourself; no agency.
  - $10-30k: editor + thumbnail designer.
  - $30k-1M+: still just editor + designer (optional Miro designer for Miro-board videos). Content agencies, scripting agencies, editing agencies, clipping agencies = "shiny object syndrome... pure cope". JJ scaled to $1.5M/mo with 1 editor + 1 designer.
- SALES
  - $0-30k: no sales team; learn DM setting, triage, dialing, discovery, pre-handling objections, pitching, objection handling yourself. Rationale: 10% commission on $10k = $1k/mo, no good rep will work for that; you can't hire/teach a skill you don't know.
  - $30-100k: 1-2 closers + 1-2 setters (you can't take 8-16 calls/day).
  - $100-250k: 3-5 closers & setters + sales manager.
  - $250k-1M: sales manager + 5-10 reps (setters + closers).
  - Hanck's agency: 25+ in-house reps (closers, setters, dialers) + sales manager, lent to clients.
- DELIVERY & RETENTION
  - $0-30k: you deliver; max ~10-15 students at $10-30k/mo.
  - $30-100k: no fulfillment team if mentorship is properly structured with group leverage.
  - $100-250k: add CSM (client success manager).
  - $1M: CSM + optional community manager (free community + group community).
  - Results -> proof/testimonials -> more clients ("infinite flywheel").
- TEAM & OPS
  - Phase summary:
    - $0-10k: no team.
    - $10-30k: editor + designer.
    - $30-100k: editor, designer, ops assistant (back end), 1-2 closers, 1-2 setters.
    - $100-250k: editor, designer (+Miro designer), ops assistant + ops manager, 3-5 closers/setters + sales manager, CSM.
    - $250k-1M+: editor, designer, ops manager + ops assistant, sales manager + 5-10 reps, CSM + optional community manager; media buyer only once paid ads start (multi-six / seven figures).
